# AI-Powered Student Productivity Assistant

This project is a simple AI & Machine Learning based web application built using Python and Flask to help students improve their study productivity.
The app learns from a student’s study behaviour and gives focus predictions, insights, and smart suggestions.

## Features

- Study session tracking

- Focus score prediction using Machine Learning

- Smart break reminders

- Study performance analytics

- Personalized insights for better study planning

- Clean and student-friendly interface

## Tech Stack

- Python

- Flask

- NumPy

- Scikit-learn
